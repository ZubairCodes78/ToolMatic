Kebijakan Privasi

Berlaku Efektif: 25 Oktober 2026. Diperbarui: Oktober 2026.

Ringkasan Privasi

ToolMatic tidak menyimpan, mengumpulkan, atau mengirimkan foto atau gambar Anda ke server mana pun. Semua file diproses 100% di browser lokal Anda. Halaman ini juga menjelaskan bagaimana pihak ketiga seperti Google menggunakan cookie untuk menayangkan iklan yang relevan.

1. Arsitektur Tanpa Upload ke Server

Berbeda dari layanan web konvensional, ToolMatic dibangun secara eksklusif dengan pemrosesan client-side di browser pengguna. Ketika Anda mengompres gambar atau mengubah format di toolmatic.site:

  • File Anda dibaca secara lokal menggunakan memori browser Anda melalui JavaScript dan HTML5 Canvas.
  • Tidak ada file yang diunggah ke internet atau disimpan di server kami.
  • Begitu Anda menutup tab browser, seluruh data sementara otomatis dihapus oleh browser Anda.

2. Kepatuhan Google AdSense & Cookie DoubleClick

Layanan ToolMatic sepenuhnya gratis dan didanai oleh penayangan iklan resmi Google AdSense. Demi transparansi dan kepatuhan terhadap kebijakan Google:

  • Cookie Pihak Ketiga: Vendor pihak ketiga, termasuk Google, menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan pengguna sebelumnya ke ToolMatic atau situs web lain di internet.
  • Cookie DoubleClick: Penggunaan cookie iklan oleh Google memungkinkan Google dan mitranya menayangkan iklan yang relevan kepada pengunjung berdasarkan kunjungan mereka ke situs kami dan/atau situs lain.
  • Cara Mematikan Iklan Personalisasi: Pengguna dapat memilih untuk menonaktifkan iklan yang dipersonalisasi dengan mengunjungi Setelan Iklan Google atau melalui AboutAds.info.

3. Analisis Web (Google Analytics)

Kami menggunakan Google Analytics untuk memantau data agregat seperti jumlah kunjungan, jenis perangkat, dan halaman yang paling sering dibaca. Data ini dianonimkan dan tidak memuat identitas pribadi maupun data file yang Anda proses.

4. Kepatuhan GDPR & Perlindungan Data

Karena ToolMatic tidak mengumpulkan atau memperjualbelikan file pengguna, privasi Anda terjamin secara teknis sejak awal. Anda berhak mengelola preferensi cookie Anda kapan saja melalui setelan browser Anda.

5. Kontak Kebijakan Privasi

Jika ada pertanyaan terkait kebijakan privasi ini, silakan hubungi kami di support@toolmatic.site.
